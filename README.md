【任务】 使用AI Coding工具，设计一个「校园食堂点评推荐」工具，帮助学生发现食堂新菜品、避开踩雷窗口。
【建议】
1. 可结合你了解到的用户痛点或需求，自由设计产品。
2. 不必追求技术细节，优先呈现产品结构和功能设计即可。

1. 仅能提交一个可在线访问的部署链接，确保作品已成功部署，而非仅本地运行。
